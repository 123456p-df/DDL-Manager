# 更新记录

## 6.2 · 2026-10-10

- 更新课程或上传作业时，自动合并个人 GitHub 仓库中的新提交；有冲突时保留内容并提供本地版本、下载版本或手动处理选项。
- 错误提示先显示失败原因，完整说明留在下方，上传失败后可直接进入冲突处理。
- 修复取回暂存内容后，系统杂项文件冲突被误报为“作业未上传”的问题。
- 没有进行中的课程合并时，只清理系统杂项的索引冲突，保留实际文件和原暂存备份；真实作业冲突仍需处理。
- 空上传列表改为直接提示没有需要上传的作业文件；修正失败提示中的旧按钮名称。
- 安装包附带已同步的上游 MIT LICENSE。

## 6.1 · 2026-10-09

- 课程窗口沿用主界面配色，简化说明和按钮名称，增加留白。
- 作业表格只保留作业、截止时间、提醒；老师原文与文件位置移到整行预览区。
- 添加课程后的提示与实际菜单名称一致，查找摘要只显示当前课程。
- 上传作业一次完成文件选择、提交和推送；冲突入口按需显示。
- 系统杂项文件不进入作业上传列表，更新课程时暂存并恢复，保留原有暂存状态和已有备份。
- 启动不再立即查找截止日期，保存并恢复上次成功结果；定时和手动查找不再锁住整个页面。
- 登录信息在本次运行中复用，登录和刷新后更新、退出后清除；拒绝授权时避免重复弹窗。

使用范围：macOS 13+、Apple 芯片。使用临时签名，未经 Apple 公证；安装新版仍可能需要首次钥匙串授权。测试使用模拟 GitHub、临时 Git 仓库和合成界面数据，真实 GitHub 网络与系统授权弹窗尚未端到端验证。
